- clone the repository to CADE machine
- make sure that you are in the correct directory Machine-Learning/Perceptron that contains all the necessary files to run the code
- perceptron.py file contains the three versions of the perceptron algorithm
- run 'chmod u+_x run.sh' command to make 'run.sh' file executable
- run './run.sh' command to run the 'run.sh' file
- results for all three algorithms will be printed to the console
